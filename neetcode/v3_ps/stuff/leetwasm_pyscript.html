1. Two Sum Easy AC 51.4%

Given an array of integers nums and an integer target, return indices of the two numbers such that they add up to target.

You may assume each input has exactly one solution and you may not use the same element twice.

Example 1
Input nums = [2,7,11,15], target = 9
Output [0,1]
nums[0] + nums[1] == 9, return [0, 1].
Example 2
Input nums = [3,2,4], target = 6
Output [1,2]
Example 3
Input nums = [3,3], target = 6
Output [0,1]
Constraints
2 ≤ nums.length ≤ 104
−109 ≤ nums[i] ≤ 109
−109 ≤ target ≤ 109
Only one valid answer exists.

Editorial
Approach 1 — Brute Force
For each element x, scan the rest of the array for the complement target − x.
O(n²) time O(1) space
Approach 2 — Hash Map Optimal
Iterate once. For each element, check if its complement already exists in the hash map. If yes — return both indices. If no — store current value → index and continue.
O(n) time O(n) space
Key insight: Checking "have I seen the complement?" is O(1) with a dict. Doing complement-check before insertion elegantly handles the edge case where a number is exactly half of target.
Reference Solution
# O(n) time, O(n) space — single pass def twoSum(nums: list[int], target: int) -> list[int]: seen = {} for idx, num in enumerate(nums): complement = target - num if complement in seen: return [seen[complement], idx] seen[num] = idx return []
