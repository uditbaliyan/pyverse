Drag & Drop

Assemble code from tokens

Missing tokens are scattered below the code. Drag the right pieces into the blank slots. No keyboard required — just reasoning about what goes where.

  • Instant visual feedback on drop
  • Wrong slots flash and reset
  • Covers expressions, keywords, operators
  • Works on mobile with touch drag

Bug Hunt

Find the broken line

A real bug is hidden in a short function. Click the offending line. You get a targeted hint — not just "wrong" — so you actually understand what happened.

  • Real Python bugs, not toy examples
  • Targeted explanations, not generic hints
  • Logic bugs, type errors, off-by-ones
  • Fixes shown in-context after solve
bug_challenge.py
BUG HUNT
click the buggy line ↓
1def greet(name):
2    return "Hello, " + name + "!"
3
4print(greet(42))  # ← something wrong here
Correct. Line 4 passes int to a function expecting str. Fix: greet(str(42))
I/O Write

Spec in, solution out

You're given an input and the expected output. Write a function that satisfies both — then run it directly in your browser via Pyodide. No server, no latency.

  • Runs real Python in the browser (Pyodide)
  • Multiple test cases checked at once
  • Encourages creative, idiomatic solutions
  • Difficulty ladder from easy to hard

Syntax Fix

Fix the broken line

The error is flagged. Type the corrected version. Builds pattern recognition for the small things — missing colons, wrong indentation, bad operators — that trip up everyone.

  • Real SyntaxErrors and IndentationErrors
  • Inline fix input, no page reload
  • Tracks which error types trip you most
  • Smart hints reveal progressively

  • Multiple choice and true/false formats
  • Explanation shown after each answer

Predict Output

Read first. Run second.

A snippet runs in your head before the computer runs it. Predict the output. This forces real understanding of execution order, scoping, and mutability — not just memorizing syntax.

  • Covers closures, mutation, iteration order
  • Graded: wrong attempts reveal a hint
  • Common Python gotchas are featured
  • Links to memory visualizer for deep dives
