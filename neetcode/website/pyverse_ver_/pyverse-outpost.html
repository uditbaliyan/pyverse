Deck Layout

Every module below was scavenged from a different, half-broken prototype and refitted to the same hull.

Station 01

Static Relay

Character-level typing drills tuned to real Python syntax. Clean keystrokes lock in instantly; static means you mistyped.

Station 02

Schematic Table

A local trace & memory visualizer. Objects and pointers render as hard rectangles and right-angle wiring — see below.

Station 03

Flight Bay

A sandboxed coding lab, split like a cockpit: your code on the left, live assertion telemetry streaming on the right.

Station 04

Cargo Manifest

Functional input → output deduction. You're handed the cargo hold's contents and have to guess what the crate does.

Station 05

Detonator

Time-decay debugging. A countdown ticks while you defuse a broken script — panic optional, partial credit given.

Station 06

Training Drone

Tactile logic modules — tokens clip into hard-bordered slots. Loud, mechanical feedback confirms every correct fit.

Station 07

Memory Core

Active-recall flashcards. No spinning transitions — the card just flips, hard, like flicking a toggle switch.

The Hull

Mission Control

The router welding all seven stations to one deck. No page reloads — panels swap in place, deck stays powered.
