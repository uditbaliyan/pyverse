1. Two Sum

Easy
Given an array of integers nums and an integer target, return indices of the two numbers such that they add up to target.
You may assume that each input has exactly one solution, and you may not use the same element twice.
Example 1
Input: nums = [2,7,11,15], target = 9 Output: [0,1]
Example 2
Input: nums = [3,2,4], target = 6 Output: [1,2]

Approach 1 · Brute Force

Check every pair of elements using nested loops. Very intuitive but inefficient for large arrays.

Time · O(n²)
Space · O(1)

Approach 2 · Hash Map (Optimal)

Store previously seen numbers in a dictionary. For each element, check whether its complement already exists.

Time · O(n)
Space · O(n)

Approach 3 · Functional / Nerdy

Use enumerate + dictionary comprehension or vectorized lookup patterns. Less readable but interesting for Python internals exploration.

Time · O(n)
Space · O(n)

Runtime Characteristics

Hash maps provide average-case O(1) lookup complexity. That allows us to solve the problem in linear time instead of quadratic time.

Space Tradeoff

We sacrifice additional memory to achieve faster lookups. The dictionary stores previously seen values and their indices.

Edge Cases

Duplicate values, negative numbers, and repeated complements are handled naturally using the dictionary approach.
